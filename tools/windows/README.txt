联想小新 风扇/散热行为采集
================================

用途：记录 Windows 下联想电脑管家 + Intel DTT 如何控制风扇和性能，
      回到 Ubuntu 后用来复刻同样的散热策略。

脚本只读：不修改任何设置，只调用 WMI 中以 Get/Is 开头、无输入参数的方法。

使用步骤
--------
1. 插上电源，关闭其他程序（浏览器、下载等）。
2. 按 Fn+Q 或在联想电脑管家里切换到要测的模式（建议先测「野兽」，有时间再测「均衡」）。
3. 双击 run-as-admin.cmd，在弹出的权限提示里点「是」。
4. 输入当前模式名称（如：野兽），回车。
5. 等待约 6～8 分钟，满载阶段注意听风扇：什么时候开始变响、多响。
6. 看到「完成！」后关闭窗口。换一个模式可以再跑一次。

（可选）安装 7-Zip（7-zip.org）后再跑，会额外测出可与 Ubuntu 直接对比的 CPU 得分。

结果在本目录的 result-日期-模式 文件夹里，回到 Ubuntu 后告诉 Claude 即可。
